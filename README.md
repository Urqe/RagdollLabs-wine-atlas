# RagdollLabs Wine Atlas

A static, interactive wine reference tool for exploring how grape variety and region shape a wine's typical style.

## Features

- Explore grape + region combinations
- Compare body, acidity, tannin, sweetness, alcohol, fruit, oak, and earthiness
- View typical aroma and flavor notes
- Get serving temperature, decanting, glassware, ageing, and food-pairing guidance
- Compare the same grape across multiple regions
- Responsive layout for desktop, tablet, and mobile

## Tech

The app is intentionally simple and public-friendly:

- HTML
- CSS
- Vanilla JavaScript
- No backend
- No authentication
- No analytics
- No external APIs

Everything is contained in `index.html`, so it can be hosted directly with GitHub Pages.

## GitHub Pages

In the repository, open:

`Settings → Pages → Deploy from branch → main → / (root)`

The expected URL is:

`https://urqe.github.io/RagdollLabs-wine-atlas/`

## Disclaimer

Wine profiles in this project describe typical regional and varietal characteristics. Individual wines may differ substantially depending on vintage, producer, vineyard, climate, and winemaking choices.
